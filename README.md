# TameableSpider

MOD changes:
Introduce Tameable Spiders, which:
* can be tamed using rotten flesh or spider eyes (33% chance)
* defend the player when attacked
* attack whatever the player attacks (tamed spiders won't attack other tamed spiders)

World changes:
Replace Spiders with Tameable Spiders

## Setup
download mod / click install
